# Tekurant — TCG-Arena files

Card images + game files for playing **Tekurant** (formerly Yosemite TCG, Core Rules V5.01) on [tcg-arena.fr](https://tcg-arena.fr).

- `Game_Tekurant.json` — board / rules config (paste its raw URL into tcg-arena.fr/build, box 4)
- `CardList.json` — Enhanced Knights + Savanna Pride (EX1)
- `decks/tekurant-decks.json` — the two 50 + 7 starter decks
- `images/` — card faces, reference cards, tokens, back, banner, table mats

Generated by `../render_tekurant.py` + `../build_tekurant_arena.py` from `Tekurant Card Database.xlsx`.
