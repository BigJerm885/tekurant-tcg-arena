# Tekurant — TCG-Arena files

Card images + game files for playing **Tekurant** (Core Rules V5.02) on [tcg-arena.fr](https://tcg-arena.fr).

- `Game_Tekurant.json` — board / rules config (paste its raw URL into tcg-arena.fr/build, box 4)
- `CardList.json` — Enhanced Knights, Savanna Pride and Rootkin Grove (EX1)
- `decks/tekurant-decks.json` — the three starter decks (50 main + 7 Adaptations)
- `images/` — card faces, reference cards, tokens, back, banner, table mats

Generated by `render_tekurant.py` + `build_tekurant_arena.py` (in the Tekurant folder's `tcg_arena/`)
from `01) Tekurant Card Database.xlsx` and the art in `Card_Art/`.
